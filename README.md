# 行途精选 AI 提示词库（xingtu-prompts）

> 拿来即用、马上能解决问题的优质提示词集合。

## 定位

- 只收录「能确实马上解决问题」的提示词，不收录花架子
- 每个提示词都是独立文件，复制即用，不依赖特定 AI 产品（豆包 / WorkBuddy / Claude / ChatGPT 等通用）
- 按场景组织：理解解释 / 思维框架 / 审查核验 / 内容写作 / 编码开发 / 复盘分析 / 自媒体运营 / 自我认知 / 售前商务

## 核心理念：为什么是「提示词」，不是「Skill」

- **轻便**：纯文本一个文件，复制即用。不安装、不配置、不依赖特定环境。
- **随时调整**：改一句话就生效，不用改代码、不用重新部署。
- **快速理解**：没有执行逻辑和依赖关系，看一眼就知道它干什么。
- **跨平台**：豆包、WorkBuddy、Claude、ChatGPT……任何 AI 都能用。

Skill 适合需要稳定执行逻辑、脚本、工具链的复杂场景；提示词适合「给 AI 一个思维框架或行为规则」的轻场景。
两者互补：Skill 里沉淀的方法论，蒸馏成提示词后，可以离开特定环境被任何人复用。

## 使用方式

1. 打开对应分类下的提示词文件
2. 复制「提示词文本」部分，发给任意 AI
3. 替换提示词中的占位内容（如「要解释的主题」）即可

## 收录标准

一条提示词要进入本库，需同时满足：

- [ ] 能马上解决某类具体问题（不是概念介绍）
- [ ] 可复制即用，不依赖特定产品
- [ ] 写明适用场景和使用方法
- [ ] 附一个真实使用示例
