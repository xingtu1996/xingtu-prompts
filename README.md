# xingtu-prompts · 精选提示词库

> 行途开源矩阵的独立提示词资产仓：把真实工程与内容生产中沉淀的高频提示词按场景分类收纳，一行触发、单文件复用。
> 同一份提示词库在 [xingtu-skills/prompts/](https://github.com/xingtu1996/xingtu-skills/tree/main/prompts) 作为技能聚合仓的镜像目录，两处保持同步、双向互链。

## 这是什么

提示词是轻量技能：一行触发、单文件、可跨工具复用。本仓从真实 AI 工程化实践中蒸馏出 80+ 条经过实战校验的提示词，覆盖编码、解释、内容、个人决策、调研、审查、销售、思考、写作九类场景。

## 目录分类

| 分类 | 目录 | 用途 |
|---|---|---|
| 编码 | `prompts/code/` | 架构图评审、契约四查、文件重构、测试阶梯、数据排查、喂给 Agent、影响分析、先查后动、最小改动、质量门禁、需求澄清、测试左移、省 token、核验即停 |
| 解释 | `prompts/explain/` | 双层解释、ELI5、外行翻译 |
| 内容媒体 | `prompts/media/` | 蓝海策略、岗位信号挖掘、月度选题复盘、个人品牌冷启动、会话沉淀 |
| 个人决策 | `prompts/personal/` | 执行状态简报、高管汇报准备、隐藏人才挖掘、人生设计、仓库台账挖掘 |
| 调研 | `prompts/research/` | ROI 量化、能力分层、会话转 spec、上下文压缩保留、跨轴分析、知识可视化、本地闭环、最小实验、日报摘要、私有模型选型、项目收尾、提示词沉淀环、调研交接、KB 元数据溯源、供应商规格自证、会话复盘、方案调研、成本趋势、收尾待办清扫 |
| 审查 | `prompts/review/` | 对抗审查、交付清单、辨识提醒、事实核查、复盘五问、AI 协作复盘、主张裁决审计、转向后文档一致性、经验转规则、PM 第一性原理挑战 |
| 销售 | `prompts/sales/` | 竞争战卡、工作量估算评审、对外披露框架 |
| 思考 | `prompts/think/` | 对抗协作、自主无人值守、复利演进、跨域迁移、专家咨询、第一性原理、专注精通、意图优于服从、判断优于执行、一次学会多次复用、提示词骨架五要素、逆向工程、简单优先、苏格拉底提问、钢人论证、决策点检查、新模型精简规则、真相优先 |
| 写作 | `prompts/write/` | 去 AI 味、外部素材脱敏、得体行文门禁、精简输出、商务友好改写、写作规范 |

## 使用方式

1. 按场景在对应分类目录找到提示词文件。
2. 复制正文到你的 Agent 会话，替换占位变量即可使用。
3. 提示词与技能互补：完整工作流见 [xingtu-skills](https://github.com/xingtu1996/xingtu-skills) 的 `SKILL.md` 技能包。
