# 行途精选 AI 提示词库（xingtu-prompts）

> 拿来即用、马上能解决问题的优质提示词集合。

## 定位

- 只收录「能确实马上解决问题」的提示词，不收录花架子
- 每个提示词都是独立文件，复制即用，不依赖特定 AI 产品（豆包 / WorkBuddy / Claude 等通用）
- 按场景组织：理解解释 / 内容写作 / 编码开发 / 自媒体运营 / 研究分析

## 目录

| 分类 | 说明 | 已收录 |
|------|------|--------|
| `prompts/explain/` | 理解与解释类：把复杂问题讲人话 | ELI5 |
| `prompts/write/` | 内容写作类 | （待收录） |
| `prompts/code/` | 编码开发类 | （待收录） |
| `prompts/media/` | 自媒体运营类 | （待收录） |
| `prompts/research/` | 研究分析类 | （待收录） |

## 使用方式

1. 打开对应分类下的提示词文件
2. 复制「提示词文本」部分，发给任意 AI
3. 替换提示词中的占位内容（如「要解释的主题」）即可

## 收录标准

一条提示词要进入本库，需同时满足：

- [ ] 能马上解决某类具体问题（不是概念介绍）
- [ ] 可复制即用，不依赖特定产品
- [ ] 写明适用场景和使用方法
- [ ] 附一个真实使用示例

## 贡献

欢迎通过 Issue / PR 提交你验证过好用的提示词，按 `prompts/` 下对应分类存放，格式参考已收录条目。
